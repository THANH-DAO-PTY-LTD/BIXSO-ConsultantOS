# Security policy

If you find a security issue, use [Report a vulnerability](https://github.com/THANH-DAO-PTY-LTD/BIXSO-Consulting-OS/security/advisories/new) to open a private report. Include the affected version, environment, impact and a minimal example using fictional data. Keep customer records and secrets out of the report. Use public issues for ordinary bugs and feedback.

Reports about recording an unsupported fact, bypassing a gate or approval, or reading another engagement's file are in scope. This is an early project maintained on a best-effort basis.
