# Source and notices

Thanh Dao Pty Ltd releases this source under the MIT license in the repository root. The engagement graph, question planner, stage assessment and option matcher were originally developed for BIXSO's consulting service and adapted for this release. Built-in stages and the built-in options catalogue were removed and replaced by playbook files; the gate evaluator, playbook loader, command line, example playbook and demo were written for this release. The examples use fictional businesses and people.

This release has no runtime dependencies beyond Node.js.
