# BIXSO Consulting OS roadmap

**Updated 28 November 2026.** Part of the [BIXSO OS roadmap](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/ROADMAP.md). This project is the open concept and lite code for the rules in [BIXSO Consulting](https://bixso.ai/?utm_source=github&utm_medium=readme&utm_campaign=bixso-os&utm_content=consulting-os).

## Now: in this repository

- An evidence ledger that keeps facts, hypotheses and evidence apart
- Stage gates that need evidence review and a person's approval
- A question planner that won't re-ask what is known, and an option matcher

## Next: help wanted

- A second sample playbook ([#4](https://github.com/THANH-DAO-PTY-LTD/BIXSO-Consulting-OS/issues/4))
- Exporting an engagement as a readable report
- Examples of an AI tool proposing hypotheses that the rules then check

Pick one up, or comment on the issue before you start. Items without an issue are open for an idea or a pull request.

## Questions for people who do this work

- What would your first stage gate check?
- How do you record that a client confirmed something?

Answer in an issue using **Share an idea**, or on [r/BIXSO](https://www.reddit.com/r/BIXSO/).

## Not planned in this repository

- BIXSO's own five-stage method and client records stay in BIXSO Consulting.

This is a direction, not a promise of dates. How decisions are made: [GOVERNANCE](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/GOVERNANCE.md).
